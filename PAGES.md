# GitHub Pages deployment

This project is configured to deploy automatically from the `main` branch using GitHub Actions.

Expected public URL:

```
https://ledinhtien219.github.io/BEHOCVUI/
```

If Pages has not been enabled for this repository yet:

1. Open **Settings → Pages**
2. Under **Build and deployment**, set **Source** to **GitHub Actions**
3. Open the **Actions** tab and run **Deploy GitHub Pages** once if needed

After that, every push to `main` deploys automatically.
